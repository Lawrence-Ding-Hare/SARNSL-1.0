# 常见问题

**公司可以内部使用或修改吗？** 可以。仅由代表同一法律主体行事的人员用于该主体内部运营时，第五条的网络服务源码义务不触发。分发副本适用第四条。

**原版二进制也要给源码吗？** 要。可随副本提供准确版本的完整对应源码，也可给接收者下载链接或书面承诺。使用后两种方式时，自最后一次分发该版本起至少三年内须让接收者免费取得源码。

**源码一定要放在公共 GitHub 仓库吗？** 可以直接向接收者提供。使用修改版网络服务的外部用户须能在服务运行期间访问对应版本的源码。源码接收者可以按本协议行使后续分发权利。

**独立组件也要提供源码吗？** 不因同包分发或仅通过 API 通信而触发。义务针对受约束作品，包括组合作品中包含或衍生自项目受保护内容的部分。

**已有公开版本会换证吗？** 此前合法授予的权利继续存在。历史版本和第三方材料分别按其发布时适用的许可使用。

**哪里注明引用？** 在随作品或服务提供的 README、关于页、法律声明或文档中写明项目名和官方 URL，并保留相关版权与署名。
