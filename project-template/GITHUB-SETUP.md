# 在 GitHub 项目中采用 SARNSL 1.0

把英文正文作为采用项目的根 `LICENSE`，将中文译文、贡献指南、第三方声明和 `docs/` 下的说明一并放入仓库。将 [README 许可段落](README-LICENSE-SECTION.md) 合入项目现有 README。其余项目介绍、鸣谢及安装说明照常保留。

在 [适用范围与署名](docs/COPYRIGHT-AND-ATTRIBUTION.md) 填写版权方、项目名、仓库 URL、首次采用版本及覆盖范围。项目包含第三方代码、媒体、工具、二进制或资料时，逐项查看原有授权，在第三方声明写明。文件中的 `LicenseRef-SARNSL-1.0` 为自定义标识，GitHub 可能显示为自定义或无法识别。

迁移现有项目时，用常规提交记录协议变更。保留原许可证和适用的版本或提交信息，以便读者辨认早期发行及其授权。已有其他权利人的材料仍按原条款使用，取得授权后才可纳入新许可。

发布时固定每个版本所附的许可证正文。项目若选用其他许可证，项目自己的许可声明优先。
