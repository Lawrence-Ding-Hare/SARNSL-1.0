# 收费规则与案例

直接衍生版包括以项目软件为主要实用功能的改版或重打包。获取、安装、激活及使用都须免费。独立付费产品可以按原价在既有相关档位集成。收费条款也适用于通过托管服务提供直接衍生版。

| 做法 | 按 SARNSL 1.0 的处理 |
| --- | --- |
| 免费发布改版，用户可选择购买单独的技术支持 | 允许。支持应真正可选。 |
| 改版下载免费，安装前必须购买安装服务或会员 | 禁止。分发和使用仍以付款为条件。 |
| 别处能免费下载，自己把同一直接衍生版装进收费包出售 | 禁止按本协议有偿分发。 |
| 原价 99 元的独立软件把项目功能加入既有相关档位，价格仍为 99 元 | 允许。原有定价应来自独立功能。 |
| 保持总价，但把相关功能从常规档移到更贵档位 | 禁止以升档作为取得该功能的条件。 |
| 新建付费产品，产品的主要实用功能来自本项目 | 按直接衍生版免费提供。 |
| 新建付费产品，有实质独立功能，将本项目作为一项附带功能 | 可以按独立功能定价。受约束功能须能在相关常规档位使用，无须为它加购或升档。 |
| 因独立功能升级或无关经营成本调整整体价格 | 允许独立定价。禁止将价格调整归因于受约束功能。 |
| 以单独购买算力或托管为使用功能的条件 | 直接衍生版不得强制购买。独立付费产品可就实际提供的独立服务收费，不能借它向受约束功能收费。 |
